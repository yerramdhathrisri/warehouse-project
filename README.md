 Warehouse Management System

A Java-based warehouse management application built using Object-Oriented Programming (OOP).

Features

Receive and dispatch goods
Manage stock quantities and product details
Support for perishable and fragile items
Calculate storage charges and dispatch bills
Search products and view inventory
Generate low-stock and expiry reports
Save warehouse data locally

Technologies & Concepts

Language: Java
Object-Oriented Programming: Classes and Objects, Inheritance, Encapsulation, Abstraction, Polymorphism
Java Concepts: Interfaces, Method Overriding, Method Overloading, Constructors, Exception Handling
Collections: ArrayList
Data Persistence: Java Serialization

Project Status

Developed as a Java learning and hackathon project.
